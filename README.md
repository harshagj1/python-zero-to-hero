# Python Zero → Hero

A complete path from school-student beginner to job-ready Python for **SRE**, **Observability**, **AI Engineering**, and **enterprise / FastAPI / REST** work.

## Start here

1. Open [`00-START-HERE.md`](00-START-HERE.md)
2. Skim [`ROLES.md`](ROLES.md) (pick SRE / Observability / AI emphasis)
3. Follow [`ROADMAP.md`](ROADMAP.md) in order
4. For each module: read `LESSON.md` → run the `.py` file (read SCHOOL/WORK/WHY comments) → do exercises

## How to become “10 YOE hands-on” with this

Courses alone don't create experience — **deliberate practice** does:

- Type code yourself
- Break it on purpose, then fix it
- Finish every checkpoint and capstone
- Rebuild features from memory a week later
- Read errors slowly
- Build one personal project beyond the syllabus

You already started tinkering in `hello.py` at the project root — keep that curiosity as you go through Module 01+.
