# Python Engineer Roadmap (Zero → Hero)

Each module has a `LESSON.md` (read first) and `.py` practice files (run second).  
Code comments are written so a **school student** can follow every line, while **WORK** notes connect the same idea to **enterprise apps, automation, FastAPI/REST, SRE, observability, and AI**.

Role tracks: **[ROLES.md](ROLES.md)**  
Estimated total: **6–12 months** at a steady pace (faster if you already code). Depth beats speed.

## Skills matrix (what “10 YOE hands-on” looks like)

After finishing this path with real practice, you should be able to:

- Design clear modules and APIs
- Use OOP and functional style appropriately
- Write tests and type-annotated code
- Talk to HTTP APIs and databases
- Debug with logs, breakpoints, and profilers
- Choose sync vs async wisely
- Ship a maintainable project, not a notebook of scraps
