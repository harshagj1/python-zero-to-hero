# Module 01 — Getting Started

## School-student idea

A **program** is a list of instructions for the computer — like a recipe.

**Python** is the language. It is used for websites, automation, AI, and reliability tools.

## Where this shows up at work

| Role | First scripts look like… |
|------|---------------------------|
| SRE | print/log “starting check”, call health URL |
| Observability | print parsed fields from one log line |
| AI Engineer | print model response text |
| FastAPI | startup logs + `/health` returns `{"ok": true}` |

## What happens when you run Python

1. You write a `.py` file  
2. You run it  
3. Python executes top → bottom  
4. Errors stop the program and teach you what broke  

## Comments in THIS course

```text
# SCHOOL: simple meaning
# WORK:   job / enterprise / FastAPI / SRE / AI use
# WHY:    engineering reason
```

A school student should understand every `SCHOOL` line.  
A future pro should also absorb every `WORK` line.

## Exercises

1. Change the greeting to your name.  
2. Print a fake service line: `service=demo status=up`.  
3. Add comments using SCHOOL/WORK style on your own lines.
