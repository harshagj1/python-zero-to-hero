# Capstone 4 — Your Own Product

## Goal

Ship something **you** care about. Ownership is the final skill.

## Pick one (or invent)

- Personal finance dashboard (CLI or API)
- Habit tracker with streaks
- Chat log analyzer
- Local markdown knowledge base search
- Automation bot for your files/folders
- Mini data pipeline: CSV → clean → SQLite → summary report

## Non-negotiables

- Clear README
- venv + dependencies pinned
- Types on public functions
- Tests for core logic
- Logging
- One paragraph: design decisions and tradeoffs

## Reflection (write in README)

1. What was hardest?
2. What would you redesign with another week?
3. Which modules from this course did you reuse?

When this is done, you're no longer “learning Python” — you're **building with Python**. Keep going.
