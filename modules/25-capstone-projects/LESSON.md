# Module 25 — Capstone Projects (Portfolio)

These projects turn lessons into **proof**. Employers and your future self care about shipped work.

## Rules of engagement

1. Build it yourself (use lessons as reference, not copy-paste entire solutions)
2. Use a venv + `requirements.txt`
3. Add a README: what it does, how to run, screenshots/sample output
4. Add tests for core logic
5. Put it on GitHub when you're proud of it

Work through in order — each project layers skills.
