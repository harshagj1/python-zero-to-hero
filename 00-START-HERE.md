# Python Zero to Hero — Start Here

Welcome. This course takes you from **school-student beginner** to **job-ready Python** for roles like:

- **SRE** (automation, reliability scripts, CLIs)
- **Observability Engineer** (logs/metrics pipelines, collectors, APIs)
- **AI Engineer** (data prep, model HTTP clients, FastAPI services)
- **Backend / enterprise apps** (REST APIs, databases, clean modules)

Same Python. Different job stories. See **[ROLES.md](ROLES.md)** for your track.

## How to use this course

1. **`LESSON.md`** — plain-English teaching (read first)
2. **`*.py` demos** — every important line has comments a school student can follow, plus a **WORK** note showing the enterprise / FastAPI / SRE / AI use
3. **Exercises** — do them without peeking
4. **Projects / Capstones** — proof you can ship

### Daily habit

| Time | What to do |
|------|------------|
| 45–60 min | Read one lesson |
| 30–45 min | Type and run the `.py` file; read every comment |
| 30 min | Exercises |
| Weekly | One mini automation or API experiment from ROLES.md |

**Rule:** If you cannot explain a line to a younger sibling in simple words, you do not own it yet.

## Comment style (very important)

```text
# SCHOOL: simple meaning — what this line is doing
# WORK:   where this appears in SRE / observability / AI / FastAPI / enterprise apps
# WHY:    why we chose this (the engineering reason)
```
